# board/ · BENCH workstream

Owner: BENCH. The board data and the physical bench.

- `solmio-v1.3.json`: board outline, mounting holes and all 93 part placements (mm, Altium frame), taken from the `Muscle_MB2` PCB. The bench screen and the simulation use the same data.
- `photos/`: reference photos of good, cold, bridged and missing joints through the wrist camera (H3). Name them `<ref>-<pad>-<label>-<n>.jpg`, for example `C4-2-cold-01.jpg`.

Parts, cups and the bench checklist: [docs/08-bench-and-parts.md](../docs/08-bench-and-parts.md).
